# studyflow-student-productivity
StudyFlow is a responsive student producitivity dashboard designed to help students organize their daily tasks,manage study goals,stay focused and track their progress in one place. 

The application provides features such as task management, task completion tracking, a Pomodoro focus timer, quick notes, daily study goals, progress tracking, dark mode, and local data storage.

Features

* 📚 Daily task management
* ✅ Task completion tracking
* 📊 Study progress percentage
* ⏱️ 25-minute Pomodoro focus timer
* 📝 Quick notes
* 🎯 Daily study goal tracking
* 🌙 Dark mode
* 💾 LocalStorage for saving user data
* 📱 Responsive design for desktop and mobile

Tech Stack

* HTML5
* CSS3
* JavaScript
* LocalStorage
* Git & GitHub
* Vercel

StudyFlow is built as a practical frontend project to demonstrate web development fundamentals, JavaScript functionality, responsive UI design, and deployment using GitHub and Vercel.
